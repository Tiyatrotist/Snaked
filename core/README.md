# snaked-core

Snaked'in Python çekirdeği: model sağlayıcıları, bilgisayar kontrolü, güvenlik politikası ve masaüstü uygulamasının bağlandığı yerel agent sunucusu.

```bash
uv sync --extra desktop
uv run snaked-core serve        # ws://127.0.0.1:8765
uv run snaked-core providers    # bağlanabilir sağlayıcıları listeler
uv run pytest
```
